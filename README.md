# ДЗ_вебсайт — АвтоСервіс PRO

Домашнє завдання: односторінковий сайт (головна сторінка) для бізнесу за
фаховою тематикою. Тема — станція технічного обслуговування автомобілів
(СТО / автосервіс) під вигаданим брендом «АвтоСервіс PRO».

## Що на сайті

- Назва компанії
- Заголовок
- Пояснення визначення (що таке СТО/автосервіс)
- Послуги
- Професійне європейське обладнання
- Графіка/таблиці

## Технології

- HTML5 (семантична розмітка)
- CSS3 (custom properties, Grid/Flexbox, без фреймворків)
- Vanilla JavaScript (без залежностей)

## Запуск локально

Відкрити файл `index.html` у браузері — збірка та встановлення залежностей
не потрібні.
